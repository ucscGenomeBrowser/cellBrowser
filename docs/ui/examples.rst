Featured Datasets
=================

The datasets below are all hosted on cells.ucsc.edu, and each one highlights a
particular Cell Browser feature. Open any of them to follow along with the
guides in this section.

**Split screen and multiomics**
   `dup15q-cortex-organoids <https://dup15q-cortex-organoids.cells.ucsc.edu>`_
   opens in split-screen mode by default, showing the spatial and snRNA-seq
   views side by side — a good example for any multiomics dataset. See
   :doc:`analysis` for split screen and :doc:`visualization` for spatial data.

**Highlighting groups in a crowded legend**
   `gbm-nvp (CellTag clones) <https://cells.ucsc.edu/?ds=gbm-nvp+nvp-celltag>`_
   uses the **Recolor checked values** button to light up a chosen set of
   CellTag-barcoded clones while greying out the rest. This is especially handy
   when a metadata field has more than about 100 values and the colors alone are
   hard to tell apart. See :doc:`visualization`.

**Visium spatial data**
   `ms-subcortical-lesions <https://ms-subcortical-lesions.cells.ucsc.edu>`_ is a
   good example of how Visium slides look in the Cell Browser. See the spatial
   transcriptomics section of :doc:`visualization`.

**MERFISH spatial data**
   `hoc <https://hoc.cells.ucsc.edu>`_ is an example of imaging-based MERFISH
   spatial data in the Cell Browser. See the spatial transcriptomics section of
   :doc:`visualization`.

**Coloring by features other than genes**
   `brain-lipids <https://cells.ucsc.edu/?ds=brain-lipids>`_ colors cells by
   different lipids rather than by gene expression — the same search-and-color
   workflow works for any measured feature, not only genes or ATAC-seq peaks.

**Trajectories and pseudotime**
   `cardiac-differentiation <https://cells.ucsc.edu/?ds=cardiac-differentiation+trajectory+cm-combined-trajectory>`_
   shows a URD differentiation trajectory.

**Lineage tracing**
   `pre-postnatal-cortex <https://cells.ucsc.edu/?ds=pre-postnatal-cortex+ex-neu+rna>`_
   is an example of a cell lineage-tracing dataset.
